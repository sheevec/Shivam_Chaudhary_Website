The problem

Equifax needed a reliable data seeding and inquiry orchestration layer connecting bureau files, FICO scores, credit profiles and transaction records, without breaking the latency that downstream credit decisioning depends on.

Incoming inquiries had to be linked to the right existing profile even when identifiers were missing or inconsistent, and the resulting features had to land in time for the decisioning systems' SLAs.

Key engineering decisions

The choices that make the system reliable, not just fast.

Tiered matching with explicit confidence

Cheap exact matches run first; fuzzier tiers only see what is still unmatched, and every link carries a confidence score downstream systems can use.

One winner per inquiry

When several tiers match, a window ranks candidates by confidence and keeps one, so profiles are never double-linked.

Hashed identifiers

Matching runs on hashed SSNs, so raw identifiers never need to enter the matching layer.

Features as dbt models

Risk features are versioned, tested SQL models, partitioned and clustered in BigQuery for fast, cheap reads by the feature store.
